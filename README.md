# Christopher Haslerud — portfolio

A standalone portfolio project inspired by the layout and visual style of Brittany Chiang’s v4 portfolio. The copy and experience details are adapted to Christopher’s Product Owner background.

## Run locally

Open `index.html` in a browser. The page uses plain HTML, CSS, and JavaScript; Google Fonts load from Google Fonts when an internet connection is available.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — colors, typography, layout, and responsive styles
- `script.js` — mobile navigation, experience tabs, and scroll effects

The original project is available at [v4.brittanychiang.com](https://v4.brittanychiang.com/).
